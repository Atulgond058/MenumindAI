## 📌 About the Project
**MenuMind AI** bridges the gap between restaurant menus and diners by leveraging modern web technologies and AI. Whether users are looking for dietary recommendations, ingredient breakdowns, or personalized meal suggestions, MenuMind AI provides an interactive and intuitive interface to make dining choices effortless.

---

## ✨ Key Features
* **AI-Powered Recommendations:** Get personalized dish suggestions based on preferences, dietary restrictions, or cravings.
* **Interactive Menu Exploration:** Easily browse through categorized food items with rich details.
* **Responsive Design:** Fully optimized for desktop, tablet, and mobile devices.
* **Fast & Lightweight:** Built for performance with smooth UI transitions.

---

## 🛠️ Tech Stack
* **Frontend:** streamlit/python
* **Backend:** python
* **AI Integration:** OpenAI / Gemini API
* **Deployment:** [Render](https://render.com)

## ⚙️ Getting Started (Local Development)

To run this project locally on your machine, follow these steps:

### Prerequisites
Make sure you have the following installed on your system:
* Node.js (v14+ recommended)
* Git

### Installation & Setup

1. **Clone the repository:**

2. npm install

3. PORT=5000
   API_KEY=your_api_key_here
   
4. npm start

🚀 Deployment
This project is currently deployed on Render.
Any pushes to the main branch automatically trigger a new deployment on Render.
